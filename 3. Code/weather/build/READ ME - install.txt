Weather – ECMWF + BOM forecasts for the NEM east coast
=====================================================

Install
1. Unzip the "Weather" folder somewhere you can write to, e.g. C:\Weather or your Documents.
   (Not "Program Files" – if you do, Weather keeps its data in %LOCALAPPDATA%\Weather instead.)
2. Double-click Weather.exe. One window opens (maximised).
3. That's it: within about a minute it fetches the latest forecasts from the cloud (small NEM-only files,
   ~20–60 MB per new forecast run) and then checks again every 15 minutes by itself.

Where the data comes from
- A job on GitHub (github.com/nguyedi123-commits/nem-weather) downloads ECMWF, BOM and the seasonal forecasts twice a
  day (about 7:30 am and 8 pm NEM time), keeps only the NEM east coast and publishes it. No key needed on this PC.
- Refresh button (top right): "From the cloud" fetches anything new right now.
  Back-up only: download directly from ECMWF on this PC (Full ~18 GB / Without ensemble ~1.5 GB / BOM only).
  For the seasonal part of a direct download, put a .cdsapirc file (Copernicus key) next to Weather.exe.

Using it
- Pages (tabs) across the top. Edit (or Ctrl+E): move / resize / add / remove panels, add / rename / copy / delete pages.
- Each panel: region and field pickers; run / vs pickers to compare with an earlier run; ⓘ explains the panel.
- About panel: forecast runs on screen, download progress, when the cloud last made data and when this PC last checked.

Where things are
- data\       forecast history (only the east coast is kept)
- settings\   your pages and screen settings
- data\weather.log   the program's log (send it if something goes wrong)
